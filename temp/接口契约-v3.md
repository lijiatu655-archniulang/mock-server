# 新源村情通 · 接口契约 v3（管理端 + 家庭）

> 约定沿用 `接口契约-v1.md`：统一 `Result{code,message,data,traceId,timestamp}`；
> 业务错误 HTTP 200，鉴权 `20001→401`、无权限 `20002→403`；分页 `page/pageSize`；ID 与金额与 v1 一致。

## 1. 角色与鉴权

- 登录返回 `user.roleCode`：`villager` / `admin`；
- 工作台接口方法/类标注 `@AdminRequired`，非 admin 返回 `20002`；
- 家庭接口仅要求登录，数据按 `user_id` 隔离。

## 3. 明细

### 3.1 工作台概览
`GET /workbench/summary`

```json
{ "pendingRequests": 1, "households": 20, "population": 70, "notices": 1, "todayRequests": 0 }
```

### 3.2 消息（通知条）
`POST /workbench/notices` 请求：`{"text":"...","type":"urgent|normal","articleId":"a1001?"}`

响应 `data`：通知对象 `{id,text,type,articleId,status,createdAt}`。

`PUT /workbench/notices/{id}`：同字段，可只传部分。

`DELETE /workbench/notices/{id}`：逻辑下架（`status=0`）。

### 3.3 诉求受理
列表 `GET /workbench/requests?status=&page=&pageSize=` 返回分页 + `list`，每项含
`{id,requestNo,type,typeLabel,title,content,status,statusLabel,userName,contactPhone,createdAt}`。

受理 `POST /workbench/requests/{id}/accept` → 状态 `ACCEPTED`，写时间轴「已受理」。

回复 `POST /workbench/requests/{id}/reply` 请求 `{"content":"..."}` → 追加 `biz_request_reply`，状态 `PROCESSING`。

办结 `POST /workbench/requests/{id}/complete` → 状态 `COMPLETED`，写时间轴「已办结」。

状态非法/诉求不存在：`40001`；越权：`20002`。

### 3.4 户籍统计
`GET /workbench/statistics/household?regionId=22022110001`

```json
{
  "households": 20, "population": 66,
  "grids": [{"gridName":"第一网格","households":7,"population":23}],
  "gender": {"male":35,"female":35},
  "ageBuckets": [{"label":"0-17","count":12},{"label":"18-59","count":43},{"label":"60+","count":15}],
  "categories": [{"label":"常住","count":18}]
}
```

### 3.5 家庭
`GET /users/family` → `{list:[{id,name,relation,gender,age,phone,idCardMasked,isGuardian}]}`

`POST /users/family` 请求 `{"name","relation","gender","age","phone","idCardMasked","isGuardian"}` → 返回新成员。

`PUT /users/family/{id}` 更新；`DELETE /users/family/{id}` 删除。非本人成员返回 `20002`。
