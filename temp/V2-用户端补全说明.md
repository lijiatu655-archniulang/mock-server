## 3. 交互闭环

### 3.1 政务申报

```text
政务首页 → 事项详情 → 在线申报
  → 填表单（text/idcard/select/radio/date）
  → 选材料（可跳过，缺项会提示）
  → 提交 → 生成办件号 SB+日期+序列
  → 我的办件 → 详情时间轴
  → 撤销 / 评价（已办结）
```

- 金额由 Mock 按事项核定（医保 38000 分），前端不传金额；
- 承诺时间自动跳过周末；
- 缺材料会写入 `missingMaterials`，详情页顶部提醒；
- 演示数据内置 3 条办件：已提交、待补正、已办结。

### 3.2 诉求 / 咨询

```text
首页九宫格 → 咨询帮办 / 诉求建议
  → 选类型（咨询/诉求/建议）
  → 填标题、情况、地点、电话、照片
  → 提交 → 我的诉求 → 详情
  → 催办（办理中）/ 评价（已办结）
```

- 内置 2 条诉求：办理中、已办结；
- 催办会写入时间轴，提示“第 N 次催办”；
- 评价后状态变为“已评价”。

### 3.3 便民服务

- 黄页：按供水/供电/燃气/供暖/维修/医疗/村务分组，一键拨号；
- 招聘：4 个岗位，薪资、人数、地点、截止时间、联系电话；
- 奶茶会：报名中/已结束，报名人数进度，点击“我要报名”本地 +1。

### 3.4 个人中心

- 我的办件、我的诉求、服务黄页入口全部可用；
- 统计数字来自 `/users/me`，提交后重新进入个人中心会刷新；
- 修改资料支持微信头像/相册 + 昵称，保存后头部头像立即更新；
- 家庭成员仍为 V3 预留，点击提示 V3 开放。

### 3.5 AI 历史

- 每次 AI 回答成功自动保存为一段会话，最多 20 段；
- 历史页展示标题、最后一条消息、消息数、时间；
- 「继续对话」把整段会话恢复到 AI 页，可接着问；
- 支持删除单段、清空全部；
- 只存本机，不上传服务器。

### 3.6 AI 小贾 聊天优化

- **会话化**：不再只存单条问答，按一段对话保存，回来能接着聊；
- **不打断阅读**：用户向上翻时不再强制滚到底部，出现「回到最新」按钮；
- **重新生成**：最后一条回答可一键重答，不重复添加用户问题；
- **反馈持久化**：赞/踩状态随会话保存；
- **离场保存**：切历史、开新对话、退出页面都会自动保存当前会话；
- **失败可恢复**：SSE 失败自动降级同步接口，错误气泡可重试。

### 3.7 资料编辑优化

- 头像支持微信头像、相册/拍照、恢复默认；
- 昵称 2—12 字校验；
- 姓名、手机号、区域、网格、门牌只读展示；
- 有改动才可保存，保存前显示 loading，保存后个人中心立即刷新；
- 头像加载失败自动回退到文字头像。

## 7. 90 秒演示（补全版）

> 首页 → 政务管理 → 医保缴费 → 在线申报：填姓名/身份证/年度/人员类别 → 选身份证材料 → 勾选承诺 → 提交 → 办件详情（已提交、承诺时间、时间轴）→ 返回个人中心 → 我的办件（3 条，含待补正/已办结）→ 打开已办结 → 评价 5 星。
> 首页 → 诉求建议 → 填“路灯不亮” → 提交 → 我的诉求 → 详情 → 催办 → 时间轴出现催办记录。
> 首页 → 服务黄页 → 一键拨号；就业招聘 → 打电话；线上奶茶会 → 我要报名。
> AI 网格员 → 问医保 → 回答 → 历史 → 再问一次。
