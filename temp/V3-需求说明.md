# 新源村情通 · V3 需求说明（管理端 + 家庭）

> 版本：V3.0 ｜ 日期：2026-11-15 ｜ 配套契约：`接口契约-v3.md`

## 1. 版本目标

在 V1（资讯/政务指南）、V2（在线申报/诉求/AI）基础上，V3 补齐**治理闭环**与**家庭场景**：

1. 登录时区分**居民 / 管理员**两种身份；
2. 新增**管理员工作台**：发布消息、受理并回复居民诉求、户籍统计；
3. 开通**家庭功能**：居民维护家庭成员，为后续代办、家庭成员业务打基础。

## 2. 目标用户与角色

| 角色 | role_code | 入口 | 可做 |
|---|---|---|---|
| 村民 | `villager` | 居民端 | 现有全部居民功能 + 家庭 |
| 管理员 | `admin` | 管理端工作台 | 消息发布、诉求受理/回复、户籍统计 |

- 登录页新增「居民 / 管理员」切换；账号决定角色，后端按 `sys_user.role_code` 判定，前端不伪造。
- 管理员账号：`13843219072 / 123456`（演示）。

## 3. 功能清单

### 3.1 登录角色选择
- 登录页在「账号密码」下增加身份切换：居民 / 管理员；
- 后端 `POST /auth/password-login` 已返回 `user.roleCode`，前端据此进入居民首页或管理端工作台；
- 管理员接口统一加 `@AdminRequired`，无权限返回 `20002`。

### 3.2 管理员工作台
| 功能 | 说明 |
|---|---|
| 概览 | 待受理诉求数、户数、人口数、通知数 |
| 消息发布 | 增删改查「首页通知条」（`cms_notice`），可设 urgent/normal |
| 诉求受理 | 查看全村诉求列表、详情；受理、回复、办结，写入时间轴 |
| 户籍统计 | 按网格统计户数/人口，性别、年龄段分布 |

### 3.3 家庭功能
- 居民维护自己的家庭成员：增删改查；
- 字段：姓名、关系、性别、年龄、电话、证件号（脱敏）；
- 权限：只能操作本人家庭（越权 `20002`）。

## 4. 数据模型新增

| 表 | 用途 |
|---|---|
| `sys_household` | 户籍户（户号、户主、网格、地址、类别、人数） |
| `sys_household_member` | 户籍成员（姓名、性别、年龄、关系、脱敏证件） |
| `user_family_member` | 居民家庭（本人维度，与户籍表解耦） |
| `sys_user.role_code` | 已有字段，新增 `admin` 值 |

## 5. 诉求状态流转

`PENDING 待受理 → ACCEPTED 已受理 → PROCESSING 处理中（回复时） → COMPLETED 已办结`

## 6. 验收标准
- 管理员登录后可进入工作台，居民登录后仍是居民端；
- 发布的通知在居民首页通知条即时可见；
- 受理/回复/办结后，居民诉求详情时间轴同步更新；
- 户籍统计数字与种子数据一致；
- 家庭增删改查仅本人可见；全部接口有自动化用例。
