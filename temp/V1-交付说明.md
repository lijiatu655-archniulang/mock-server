## 4. 视觉与交互

### 4.1 视觉令牌

| 元素 | 值 | 用途 |
|---|---|---|
| 主红 | `#C4161C` | 导航、按钮、选中态、TabBar |
| 深红 | `#8E0F14` | 头部渐变起点、印章 |
| 亮红 | `#D9372C` | 头部渐变收尾 |
| 暖橙 | `#E8641B` | 乡风纪实点缀、辅助标签 |
| 金 | `#C99437` / `#F2C87E` | 党徽感印章、横幅数字 |
| 暖白底 | `#F6F2F0` | 页面底色，避免纯白刺眼 |
| 正文 | `#202124` / `#4B4F55` | 标题 / 正文 |
| 卡片圆角 | `24rpx`；胶囊 `999rpx` | 柔和、政务但不呆板 |

- 首页头部用「深红 → 主红 → 亮红」渐变 + 细斜纹 + 金色光晕，保留党徽位置但**没有伪造党徽图形**，用金色五角星印章表达官方感；
- 一屏最多一个主色块，资讯区用白卡留白，避免“全屏红”；
- 所有图标为本地 PNG，不依赖网络；TabBar 图标 81×81，九宫格 96×96。

### 4.2 老年友好（落到具体值）

- 正文 30rpx、标题 34—42rpx，行高 1.7—1.9；
- 所有可点区域 ≥ 88rpx（资讯行 96rpx、按钮 88rpx、菜单行 104rpx）；
- 不用纯图标导航，图标必带文字；
- 表单一行一个，动态表单只读预览也不做两列；
- 错误提示写“怎么办”，如“首页暂时没有加载出来 → 重新加载”。

### 4.3 四态齐全

首页、资讯列表、资讯详情、政务列表、政务详情、AI 均有：**加载骨架 / 空态 / 错误重试 / 未登录或未开放引导**。

### 4.4 AI 的可信感

- 回答附「依据 · N 条」，可点进政策原文或事项详情；
- 固定免责声明（输入框上方）；
- 推荐问题 4 个，降低“不知道问什么”；
- 停止生成按钮 + “已停止生成”标记；
- 查不到时明确说“没查到”，给村委电话，不编造；
- 赞/踩只做轻提示，不打断对话。
