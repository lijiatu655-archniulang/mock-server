# temp · V1 资料与工具

| 文件/目录 | 用途 |
|---|---|
| `05-设计思路与版本功能清单.md` | 你的原始设计文档副本（v1 范围、ADR、版本清单） |
| `接口契约-v1.md` | 前后端分离的唯一契约：Result、错误码、字段、SSE；V2 已实现，V3 预留 |
| `接口总表.md` | 52 个接口一页总览（V1 26 / V2 14 / V3 10 / V4 2），可直接转给后端 |
| `V2-用户端补全说明.md` | 本次补全：在线申报、我的办件、诉求、黄页/招聘/奶茶会、AI 历史、头像 |
| `V1-交付说明.md` | 本次交付清单、运行方式、验收对照、V2 建议、待你拍板的 5 件事 |
| `mock-server/` | 零依赖 Node 服务，真实 HTTP + SSE，验证前端切换 `USE_MOCK=false` |
| `tools/gen_icons.py` | 用 Pillow 生成 TabBar/九宫格/功能图标，改色改形直接重跑 |

## 快速入口

- 跑小程序：用微信开发者工具导入 `../cilent`
- 跑 Mock 服务：双击 `mock-server/start.cmd`
- 看接口：打开 `接口契约-v1.md`
- 看下一步：打开 `V1-交付说明.md` 第 7、8 节

> 说明：金额、时限、电话、备案号均为演示样例；真实信息由村委/县政务平台核定后替换。
