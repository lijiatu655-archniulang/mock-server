# 后端语音朗读（TTS）需求

> 前端已在 AI 小贾右上角加入「声音开关」，支持自动朗读、逐条朗读、中文/朝鲜语。
> 前端实现是**插件优先**：中文优先调用「微信同声传译」插件（WechatSI），插件不可用或朝鲜语时回退到后端 TTS。
> 所以后端只需要补**朝鲜语 TTS**（以及插件不可用时的兜底）。

## 0. 插件配置（当前未启用，需账号授权后再加）

> 现状（2026-11-17）：`appid wx2bfc9ee3e046f12e` 未授权 WechatSI，开发者工具报
> `provider:wx069ba97219f66d99 ... user uin can not visit app`，模拟器无法启动。
> 为保证项目能跑，**`app.json` 里的 `plugins` 已临时移除**，前端会自动跳过插件、全部走后端 `/ai/tts`。

账号完成授权后，可以在 `cilent/app.json` 末尾加回：

```json
"plugins": {
  "WechatSI": {
    "version": "0.3.6",
    "provider": "wx069ba97219f66d99"
  }
}
```

授权路径：

```text
小程序后台 → 设置 → 第三方设置 → 插件管理 → 添加插件 → 搜索「微信同声传译」
```

加上后前端会自动优先用插件，插件失败再回退后端，代码不用改。

插件当前主要用于**中文朗读**；插件是否支持 `ko_KR` 需要实测，朝鲜语建议直接由后端合成。

## 1. 前端现状

- 合成顺序：`WechatSI.textToSpeech`（若已授权）→ 失败/不支持 → 后端 `/ai/tts`；
- 当前插件未声明，因此中文、朝鲜语都走后端 `/ai/tts`；
- 入口：AI 小贾页面右上角扬声器按钮，开/关状态存本地 `xct_tts`；
- 开启后，回答生成完成会自动朗读；关闭则停止朗读；
- 每条回答的工具条上有「朗读 / 停止」按钮；
- 切到新对话、重新提问、离开页面会自动停止播放；
- 语言取自当前界面语言：中文 `zh`，朝鲜语 `ko`；
- 前端把长文本按标点切成不超过 110 字的片段，逐段请求音频，顺序播放。

## 2. 前端请求格式

前端用 `wx.createInnerAudioContext()` 直接播放远程音频，**不能携带请求头**，所以 token 只能放在查询参数里，或接口本身允许匿名访问。

### 方案 A（推荐）：GET 返回音频流

```http
GET /api/v1/ai/tts?text=<经过 URL 编码的文本>&lang=zh&token=<登录 token>
```

响应：

```http
HTTP/1.1 200 OK
Content-Type: audio/mpeg
Cache-Control: public, max-age=86400
```

返回 MP3（或 AAC）二进制，`InnerAudioContext` 直接可播。

### 方案 B：先取音频地址，再播放

```http
POST /api/v1/ai/tts
Authorization: Bearer <token>
Content-Type: application/json

{ "text": "今年医保每人 380 元", "lang": "ko" }
```

```json
{ "code": 0, "data": { "url": "https://<host>/static/tts/xxxx.mp3", "durationMs": 3200 } }
```

前端会优先使用 `config.TTS_URL`，留空时默认请求 `BASE_URL + '/ai/tts'`。
如果要走方案 B，需要后端同事告知，前端改成先 POST 再播放（少量改动）。

## 3. 参数

| 参数 | 必填 | 说明 |
|---|---|---|
| `text` | 是 | 待朗读文本，最长 110 字；已去掉 markdown 和「（依据：…）」 |
| `lang` | 否 | `zh`（默认）或 `ko`；`ko` 用朝鲜语发音 |
| `token` | 否 | 登录 token，方案 A 用它做鉴权 |

## 4. 语音要求

- **中文**：普通话，女声优先，语速 0.95—1.0，适合政策播报；
- **朝鲜语**：延边地区通用朝鲜语发音，女声优先，语速 0.95；
- 不要读出 markdown 符号、括号引用、URL；
- 数字按中文/朝鲜语自然读法（380 读「三百八十」/「삼백팔십」）。

建议接入：

- Azure 语音服务：`zh-CN-XiaoxiaoNeural`、`ko-KR-SunHiNeural`；
- 或科大讯飞在线合成；
- 或 Edge TTS（免费，但稳定性需评估）。

## 5. 缓存与限流

- 按 `md5(text + lang + voice)` 缓存音频文件，命中直接返回，避免重复合成；
- 单用户每分钟限 60 次，超出返回 429；
- 单次文本超过 500 字返回 40001；
- 文本为空返回 40001。

## 6. 错误约定

| 情况 | 返回 |
|---|---|
| 参数缺失/为空 | `40001` JSON |
| 未登录（方案 A 校验 token 失败） | `20001` JSON |
| 合成服务不可用 | `50000` JSON，前端提示「语音朗读暂不可用」 |
| 超限 | `42900` JSON |

注意：返回 JSON 时前端播放会失败并提示，不会崩溃。

## 7. 隐私

- 文本只用于合成，不落库、不写日志全文；
- 如需日志，只记录字数、语言、耗时和 md5；
- 不缓存包含手机号、身份证号的原文音频超过 24 小时。

## 8. 验收

1. `GET /ai/tts?text=今年医保怎么缴&lang=zh` 返回可播放 MP3；
2. `lang=ko` 返回朝鲜语语音；
3. 110 字文本正常合成，超过 500 字返回 40001；
4. 相同文本第二次请求命中缓存，响应时间明显下降；
5. token 无效返回 20001，不返回音频；
6. 前端开启声音开关后，回答结束能自动朗读，关闭后立即停止；
7. 切页面、新对话不会继续播放。

## 9. 需要后端确认

- 选方案 A 还是方案 B；
- 使用哪家语音服务、是否已有账号和额度；
- 朝鲜语是否需要区分延边口音与标准朝鲜语；
- 是否需要按用户角色限制次数；
- 是否允许匿名访问（方便未登录试听政策播报）。
