## B1 摘要（双语）

- 所有面向用户的接口接受 `X-Lang: zh|ko` 或 `?lang=ko`；
- 每条数据返回 `i18n.ko`，前端自动覆盖展示字段；
- 覆盖：首页、资讯、政务、诉求、工作台、便民服务、用户、字典、错误提示、AI；
- 缺失翻译回退中文，不报错；
- 用户自己填写的内容不翻译。

验收：`X-Lang: zh` 与现在完全一致；`X-Lang: ko` 时上述模块显示朝鲜语；缺翻译回退中文。

## B2 摘要（图片）

- `cms_notice.images JSON`：通知配图，最多 3 张；
- `biz_request_reply.images JSON`：回复时现场/办理图片，最多 3 张；
- 接口 `POST/PUT /workbench/notices`、`POST /workbench/requests/{id}/reply` 接收 `images: string[]`；
- 居民端 `GET /requests/{id}` 的 `replies[]` 返回 `images`。

验收：发布带图通知后居民首页可见；回复带图后居民诉求详情可见；旧数据 `NULL` 兼容。

## B3 摘要（语音朗读）

- 语音合成由后端提供：GET /api/v1/ai/tts?text=&lang=zh|ko&token= 返回 MP3；
- 文本已切段 ≤110 字，支持缓存和限流；
- 后端未就绪时前端只提示，不会崩溃。
